IoT Based Smart Paperweight

📌 Project Overview

The IoT Based Smart Paperweight is an innovative electronic project designed to provide convenient wireless control of electrical appliances such as lights and fans.

The project combines a compact paperweight design with electronic control and sensor-based interaction. It is designed to allow users to control appliances through simple interactions while keeping the device compact and easy to use.

This project was developed as an academic project by students of Diploma in Computer Engineering.

⚙️ Working Principle

The system is divided into two main sections:

Transmitter

The transmitter section contains components used to detect user interaction and transmit control signals.

The presentation includes components such as:

* Arduino Nano
* Gyroscope / motion sensor
* RGB LED
* Touch sensor
* Wireless communication module
* Battery management system
* Battery
* Charging coil

The user’s interaction with the paperweight is detected and converted into a control signal.

Receiver

The receiver section receives the wireless signal and performs the required appliance-control operation.

The receiver includes:

* Wireless communication module
* Relay
* Servo motor

The received control signal is used to operate the connected electrical load.

🏗️ System Architecture

The system follows a transmitter-receiver architecture.

The system consists of transmitter and receiver sections. User interaction is detected by the sensors in the smart paperweight, and the corresponding control signal is transmitted wirelessly to the receiver.
The receiver operates the connected electrical load through the control circuit.
